Visual SLAM Benchmarking & Failure Analysis

Description

A UIUC graduate project (ENG 573) sponsored by GE Aerospace, aimed at improving UAV navigation in GPS-denied environments. We compared three monocular Visual SLAM algorithms across public datasets and investigated whether tracking failures could be predicted in advance. My role was benchmarking the algorithms and building the failure-analysis pipeline.

Overview

  1. Visual SLAM Benchmarking
  2. Tracking-Failure Analysis

1) Visual SLAM Benchmarking

Implementation

ORB-SLAM3 (feature-based), OpenVSLAM (feature-based) and LSD-SLAM (direct, intensity-based) were run on the EuRoC MAV dataset and the Kagaru airborne stereo dataset. Output trajectories were aligned to ground truth and evaluated with Absolute Pose Error (APE) and Relative Pose Error (RPE).

Result

OpenVSLAM was the most accurate and robust overall. On Kagaru, the longest trajectory, the algorithms recovered from tracking loss very differently: OpenVSLAM merged disconnected segments back into one global map (though it took longer to recover), ORB-SLAM3 created several submaps but kept only the first, and LSD-SLAM could not relocalize in areas it had not seen before.

2) Tracking-Failure Analysis

Implementation

To see whether failures could be predicted, I extracted image features (Laplacian variance, entropy, brightness, contrast, disparity) and motion parameters (linear and angular velocities and their changes) from the EuRoC V203 sequence. The pipeline normalized and resampled the data, tested stationarity with the Augmented Dickey-Fuller test, selected features with Granger causality, chose the lag order with AIC, and fit Vector Autoregression (VAR) and univariate AutoReg models. Residuals were then summed over 1-second windows to look for early-warning signals.

Result

The models predicted the features closely, but high residuals did not consistently line up with tracking failures, so no reliable early-warning signal was found. Next steps would be addressing non-stationarity and trying classification models on a larger set of failure cases.
